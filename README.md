# GestionFormations

A dynamic web application for training management, developed using PHP and MySQL. The platform allows users to explore available training programs, view course details, and submit registration requests through a simple and user-friendly interface.

## Technologies
- PHP
- MySQL
- HTML5 & CSS3
- JavaScript
- PDO

## Key Features
- Browse available training programs.
- View training details and information.
- Register for training programs.
- Manage registration and payment information.
- Validate user inputs and handle errors.

## Security Practices
- PDO prepared statements to prevent SQL injection.
- Input validation and sanitization.
- HTTP POST request verification.
- Structured database operations.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/LINAAAA55/GestionFormations.git
   ```
2. Move the project into the XAMPP `htdocs` directory.
3. Start Apache and MySQL.
4. Import `database.sql` using phpMyAdmin.
5. Access the application at:

   `http://localhost/GestionFormations/`
